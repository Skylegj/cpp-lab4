# Лабораторная работа №4: Обработка массивов

## Автор

Чеботников А.В. (Вариант 30)

## Цель

Изучение двумерных массивов, вложенных циклов for и условных операторов if в C++ на примере обработки квадратной матрицы.

## Описание

Программа обрабатывает квадратную матрицу B, элементы которой вводятся с клавиатуры.

Выполняются следующие операции:

- Поиск максимального элемента над главной диагональю.
- Поиск минимального элемента под главной диагональю.
- Определение позиций найденных элементов.
- Обмен найденных элементов местами.
- Вывод исходной и изменённой матриц.

Если подходящих элементов с одинаковыми значениями несколько, выбирается первый при просмотре матрицы по строкам.

Для обработки матрицы используются вложенные циклы for и условные операторы if. Обмен элементов выполняется с помощью временной переменной.

## Исходные данные

Пользователь вводит с клавиатуры:

- Порядок квадратной матрицы от 2 до 20.
- Значения элементов матрицы в диапазоне от -1000 до 1000.

Для проверки программы используется матрица размером 3×3:

    1 8 3
    4 5 6
    7 2 9

## Ожидаемые результаты

Программа выводит исходную матрицу, найденные максимальный и минимальный элементы, их позиции и матрицу после обмена.

Для приведённого примера:

- Максимальный элемент над главной диагональю: 8, позиция [1][2].
- Минимальный элемент под главной диагональю: 2, позиция [3][2].

Матрица после обмена:

    1 2 3
    4 5 6
    7 8 9

При некорректном вводе или нарушении допустимых границ программа выводит `INVALID`.

## Запуск программы

1. Открыть файл решения `.sln` или `.slnx` в Visual Studio.
2. Собрать проект.
3. Запустить программу сочетанием Ctrl + F5.
4. Ввести порядок матрицы и её элементы в консоли.
5. Получить исходную матрицу, найденные значения и результат обмена.
